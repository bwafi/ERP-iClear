## I. TUJUAN

Pedoman Sistem Pendapatan Berbasis KPI merupakan ketentuan perusahaan dalam menetapkan, mengukur, dan menghitung pendapatan karyawan berdasarkan tingkat pencapaian kinerja.

Tujuan:
1. Menetapkan sistem penghasilan yang objektif dan terukur.
2. Menghubungkan target perusahaan dengan kinerja setiap jabatan.
3. Memberikan dasar yang jelas dalam menentukan Tunjangan Kinerja.
4. Mendorong setiap karyawan mencapai target sesuai tanggung jawabnya.
5. Menciptakan sistem penilaian yang transparan dan dapat dipertanggungjawabkan.

---

## II. PRINSIP DASAR

Sistem pendapatan iClear menggunakan alur:

```
TARGET → REALISASI → ACHIEVEMENT → BOBOT KPI → KPI AKHIR → TUNJANGAN KINERJA → TOTAL PENDAPATAN
```

- Tiap jabatan dinilai berdasarkan indikator sesuai tanggung jawab dan kewenangannya.
- Perusahaan membedakan antara **Target HO** dan **Target Team Cabang**.

---

## III. STRUKTUR PENDAPATAN

## VII. KETENTUAN ACHIEVEMENT

1. Realisasi di bawah batas minimal → **Achievement 0%**
2. Realisasi mencapai batas minimal → **Achievement 0%**
3. Realisasi di antara batas minimal dan target → **dihitung proporsional**
4. Realisasi mencapai target → **Achievement 100%**
5. Realisasi melebihi target → **Achievement tetap 100%**

### Rumus Achievement

```
Achievement = (Realisasi − Batas Minimal) ÷ (Target − Batas Minimal) × 100%
```

**Achievement tidak diperbolehkan melebihi 100%.**

## XIX. RUMUS TUNJANGAN KINERJA

```
Tunjangan Kinerja = KPI Akhir × Maksimal Tunjangan Kinerja
```

### Contoh Manager
```
KPI Akhir = 90%
Maks. Tunjangan Kinerja = Rp 2.250.000

90% × Rp 2.250.000 = Rp 2.025.000

Total Pendapatan = Rp 1.500.000 + Rp 250.000 + Rp 2.025.000 = Rp 3.775.000
```
